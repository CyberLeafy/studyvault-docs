# Import Your First File

StudyVault allows you to import screenshots and PDFs directly from the Android Share menu.

### Step 1: Open Your File

Open any screenshot from your Gallery, or a PDF from your Files app, Downloads, or any other supported app.

### Step 2: Share the File

Tap the **Share** button and select **StudyVault** from the list of available apps.

You can share one file or select multiple files at once.

### Step 3: Choose Where to Save

Select:

- Subject
- Chapter
- Section

:::warning
If they don't exist yet, create them before saving.
:::

### Step 4: Save

Choose the section to save your file into.

Your screenshots and PDFs will be stored locally and organized under the selected section.

### View Your Files

Open the selected section to view the imported files. Use the **All**, **Images**, and **PDFs** filters to find what you need quickly.

:::tip
Importing through the Share menu is the fastest way to organize your study material.
:::
