# First Launch

Welcome to **StudyVault**!

The first time you open the app, StudyVault automatically prepares everything you need to start organizing your study screenshots.

## What happens on first launch?

- Initializes the local database.
- Creates the required storage directories.
- Loads the default app data.
- Prepares the app for offline use.

No internet connection or account is required.

## Start Organizing

To begin using StudyVault:

1. Create or select a subject.
2. Create a chapter inside the subject.
3. Create a section inside the chapter.
4. Import your study screenshots.

## Your Data Stays on Your Device

StudyVault stores all screenshots and data locally on your device.

Your information is never uploaded to any server.
