# Installation

This guide walks you through installing StudyVault on your Android device.

## Requirements

Before installing, make sure your device meets these requirements:

- Android 10 or later
- At least 50 MB of free storage
- Permission to install apps from unknown sources (if installing the APK manually)

## Download the APK

Download the latest version of StudyVault.

> **Download:** <Link to={siteConfig.urls.download}>StudyVault APK</Link>

:::tip

Always download the latest version of StudyVault from the official download page.

:::

## Install the APK

1. Open the downloaded APK file.
2. If prompted, allow installation from unknown sources.
3. Tap **Install**.
4. Wait for the installation to finish.
5. Tap **Open** to launch StudyVault.

## First Launch

When you open StudyVault for the first time, the app will create its local storage and initialize the database automatically.

No account or internet connection is required.
