# Gallery

The Gallery displays all screenshots and PDFs saved inside a section.

## Filter Your Files

Use the filter bar at the top to switch between:

- **All**: every file in the section.
- **Images**: screenshots and photos only.
- **PDFs**: PDF files only.

Each filter shows how many files it contains.

## View Images

Tap any screenshot to open it in full-screen mode.

### Full-Screen Viewer

The built-in image viewer supports:

- Swipe left and right to browse images.
- Pinch or double-tap to zoom in and out.
- Portrait and landscape viewing.

## Open PDFs

PDFs appear as tiles with a PDF badge and the file name. Tap a PDF tile to open it in the built-in PDF viewer.

## Add Files

Tap the **+ add file** button and choose what you want to add:

- **Image**: select images from your device.
- **PDF**: select PDF files from your device.

You can select **multiple files at once** and save them to the current section.

## Delete Files

To remove a screenshot or PDF:

1. Long press the file.
2. A delete confirmation dialog will appear.
3. Tap **Delete** to permanently remove the file.

:::danger
Deleted files cannot be recovered.
:::

:::tip
- Save related screenshots and PDFs in the same section.
- Use the **Images** and **PDFs** filters to find files faster.
- Use multiple file selection to import faster.
- Rotate your phone to read PDFs and images more comfortably.
:::
