# Screenshot Gallery

The Screenshot Gallery displays all screenshots saved inside a section.

## View Images

Tap any screenshot to open it in full-screen mode.

### Full-Screen Viewer

The built-in image viewer supports:

- Swipe left and right to browse images.
- Pinch to zoom in and out.
- Smooth full-screen viewing.

## Add Images

Tap the **Add Image** button to select images from your device.

You can select **multiple images at once** and save them to the current section.

## Delete Images

To remove a screenshot:

1. Long press the image.
2. A delete confirmation dialog will appear.
3. Tap **Delete** to permanently remove the image.

:::danger
Deleted screenshots cannot be recovered.
:::

:::tip
- Save related screenshots in the same section.
- Use multiple image selection to import screenshots faster.
- Open images in full-screen mode for easier reading.
:::
