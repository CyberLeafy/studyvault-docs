# Sections

Sections help you organize screenshots within a chapter.

Every screenshot is saved inside a section, making it easier to keep different types of study material separate.

## Common Examples

You can create sections such as:

- Notes
- DPP
- PYQ
- Assignments
- Revision
- Formula Sheet

## Create a Section

1. Open a chapter.
2. Tap the **Add** button.
3. Enter a section name.
4. Tap **Create**.

The new section will appear in the section list.

## Rename a Section

1. Long press the section.
2. Open **Rename** box.
3. Rename existing **section** name.
4. Save your changes.

## Deleting Sections

:::important

Sections **cannot be deleted**.

This helps maintain a consistent study structure and prevents accidental loss of organized screenshots.

:::

:::tip

Create separate sections for different types of study material. For example:

- **Notes** – Class notes and handwritten notes.
- **DPP** – Daily Practice Problems.
- **PYQ** – Previous Year Questions.
- **Revision** – Important revision screenshots.

:::
