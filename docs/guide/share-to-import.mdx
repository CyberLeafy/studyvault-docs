# Share to Import

StudyVault allows you to import screenshots and PDFs directly from any app that supports Android's Share menu.

This is the fastest way to organize your study material without opening the app first.

## Select Files

1. Open any app that contains your screenshots or PDFs, such as Gallery, Files, or Drive.
2. Select one or more files.
3. Tap **Share**.
4. Choose **StudyVault** from the share menu.

## Preview Files

After selecting StudyVault, the app opens an import screen where all selected files are displayed as previews.

- Images appear as thumbnails.
- PDFs appear as tiles with a PDF badge and the file name.

The screen also shows how many images and PDFs you selected. Review them before saving.

## Choose a Destination

1. Select a **Subject**.
2. Select a **Chapter**.
3. Tap the desired **Section**.

### Missing Chapters or Sections?

:::info
If the selected subject does not contain a chapter, or the selected chapter does not contain a section, create them before importing your files.
:::

Once the required chapter and section are available, continue with the import process.

## Automatic Import

As soon as you tap a section:

- Every selected image and PDF is automatically imported.
- Files are saved to the selected section.
- The section gallery opens automatically after the import is complete.

No additional confirmation is required.

## Multiple File Support

StudyVault supports importing multiple screenshots and PDFs in a single operation, making it easy to organize an entire study session in just a few taps.

:::tip
Create your chapter and section structure before importing files. This makes the import process faster and keeps your study material well organized.
:::
