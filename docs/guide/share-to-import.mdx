# Share to Import

StudyVault allows you to import screenshots directly from any app that supports Android's Share menu.

This is the fastest way to organize your study screenshots without opening the app first.

## Select Images

1. Open any app that contains your screenshots.
2. Select one or more images.
3. Tap **Share**.
4. Choose **StudyVault** from the share menu.

## Preview Images

After selecting StudyVault, the app opens an import screen where all selected images are displayed as previews.

Review the images before saving them.

## Choose a Destination

1. Select a **Subject**.
2. Select a **Chapter**.
3. Tap the desired **Section**.

### Missing Chapters or Sections?

:::info
If the selected subject does not contain a chapter, or the selected chapter does not contain a section, create them before importing your screenshots.
:::

Once the required chapter and section are available, continue with the import process.

## Automatic Import

As soon as you tap a section:

- Every selected image is automatically imported.
- Images are saved to the selected section.
- The section gallery opens automatically after the import is complete.

No additional confirmation is required.

## Multiple Image Support

StudyVault supports importing multiple screenshots in a single operation, making it easy to organize an entire study session in just a few taps.

:::tip
Create your chapter and section structure before importing screenshots. This makes the import process faster and keeps your study material well organized.
:::
